# Football Player Portfolio Website

A modern, responsive portfolio website for professional football players built with HTML, Tailwind CSS, and JavaScript.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Beautiful gradient designs and smooth animations
- **Interactive Elements**: 
  - Animated skill bars
  - Counter animations for statistics
  - Smooth scrolling navigation
  - Mobile-friendly hamburger menu
  - Photo gallery with modal view
  - Contact form
- **Sections**:
  - Hero section with player introduction
  - Season statistics dashboard
  - Career timeline
  - Skills and attributes
  - Photo gallery
  - Contact information

## Technologies Used

- **HTML5**: Structure and content
- **Tailwind CSS**: Styling and responsive design (via CDN)
- **JavaScript**: Interactivity and animations
- **Font Awesome**: Icons (via CDN)
- **Google Fonts**: Poppins font family

## Installation

1. Create a new folder for your project
2. Save the `index.html` file in the folder
3. Save the `script.js` file in the same folder
4. Open `index.html` in your web browser

That's it! No build process or dependencies required.
